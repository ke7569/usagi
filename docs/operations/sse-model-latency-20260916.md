## 两步分别做了什么

### 1. 保持数值不变的矩阵优化

在加载模型时，将四个 384×128 GRU 权重矩阵排列成四行交错、每组十六列的小块。计算时顺序读取相邻内存，复用输入向量，保留原来的分组累计及最后求和顺序。磁盘模型文件格式不变，重排仅发生在内存中。

单独启用此布局时，40,170 次连续递归更新的预测与隐藏状态均与旧版逐位一致；另有 30 组随机矩阵直接核对原内核与重排内核，逐位一致。

### 2. 向量激活与 FMA

GRU 矩阵使用显式 FMA；sigmoid 与 tanh 使用项目已有 Eigen 的 AVX 向量数学实现，一次处理八个神经元。没有引入新的数学库。模型编译目标开启 AVX2/FMA，并保留 `-ffp-contract=off`，未启用全局 fast-math。

固定输入、同 CPU 144 的独立模型测试：

| 实现 | 连续推理 P50，µs |
|---|---:|
| 原实现、GCC 4.8 | 87.761 |
| 精确矩阵布局 | 83.421 |
| 布局＋向量激活 | 55.821 |
| 布局＋向量激活＋FMA | 46.231 |

最终保留现有 GCC 4.8，未切换整个程序的编译器。试验过的 GCC 11 / AVX512 版本没有部署。

缓存干扰实验：每次计时前遍历 8MiB 内存，遍历本身不计时；原版 P50 98.341µs，最终方案 71.121µs。这只是受控缓存实验，不是实盘股票排队。
