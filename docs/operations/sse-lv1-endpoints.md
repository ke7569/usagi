## 中畅 L1

参考材料另列出中畅 L1 服务器：`10.35.80.210:10052`、`10.35.80.211:10052`。这是厂商行情服务端点，文档未注明传输协议；它不是上面的 FPGA UDP 组播地址，当前离线阶段不连接。

## 配置对应关系

- 原始 UDP 观察器：`config/examples/sse/sse_udp_observer.example.json`
- FPGA 行情模板：`config/examples/sse/sse_fpga_md_config.example.json`
- 共享 socket 层：`common/stream/UdpChannelRuntime.*`

所有地址均为参考材料中的采购/部署信息，开盘前仍需用现场实际网卡、VPN/交换机权限和厂商确认结果复核，不在代码中写死为生产连接保证。
