## 改动原理

1. **确认 AVX512 实际可用。** 机器 CPUID 表明支持 AVX512F/FMA，XCR0 为 `0x2e7`，包含 SSE、AVX、opmask 与 ZMM 状态；单独测试成功执行了 AVX512 指令。但 GCC 11 生成的 CPU builtin 在此环境中返回 `avx512f=0`、`fma=0`，可执行文件引用的是旧 `__cpu_model@GCC_4.8.0`。因此早先标记为 AVX512 的候选实际走了回退，不能用那些数字评价 AVX512 性能。
2. **按输出行组织向量。** 权重加载时重排为每块 16 个输出行、块内按输入列连续排列；广播一个输入值后，一条向量 FMA 同时更新 16 个输出。
3. **增加独立累计链。** GRU 每次处理 96 个输出行，即六个 16 行块；每块四条独立累计链，共 24 个向量累加器。相比单条长依赖链，提高了可并行执行的指令数量。改变求和顺序会引入微小浮点差异。
4. **输入投影也使用专用矩阵内核。** 128×50 投影每次处理 32 行，显式处理最后两列；输出头维持原实现。
5. **只为新内核使用新编译器。** `v06_matrix_kernels.cpp` 单独用已有 GCC 11 编译，只暴露普通指针和标量参数。模型类、激活函数、其余应用对象和原 C++ ABI 仍使用原编译环境。

运行时直接检查 CPUID、FMA、OSXSAVE 和 XCR0，不依赖此环境中错误的 builtin 结果。保留当前 AVX2 实现作为回退。模型磁盘文件及类布局没有改变。

本轮也试验了更多分块数和缓存行对齐；额外对齐没有稳定改善热缓存速度，未采用。未采用 FP16 权重或进一步简化激活。

## 正确性与精度

以当前约 48µs 版本作为参考，从开盘连续回放到约 14:25，新旧独立维护每只股票的递归状态，共核对 **7,496,541 次预测**：

- 最大四头预测绝对差：**1.04904×10⁻⁵**。
- 最大隐藏状态绝对差：**1.17123×10⁻⁵**。
- 相对当前版本的四头方向判断差异：**2 次**，均为一个输出头在约 10⁻⁷ 附近跨零。
- 涉及 **601233、603986**，今日配置均为 `static_position=0`。
- 当前配置的 paper 回放 **10 笔报单、10 笔撤单**，除异步回放产生的时间戳外，全部字段及顺序一致，包括股票、方向、价格、数量、订单号与撤单标记。

误差远低于用户允许的最终预测绝对误差 **1e-2**，但并非逐位等价；不能据当前配置的报单一致性保证未来所有临界信号永远相同。

测试包括：

- AVX512 真正执行的 200 组随机矩阵（两种形状），与双精度参考核对结果及输出边界。
- 当前 AVX2 精确布局与向量激活测试。
- 原有 4,017 行模型 golden 测试通过，最大预测误差约 1.25×10⁻⁶。
- 强制禁用 AVX512 的回退测试：40,170 步预测和隐藏状态与当前 AVX2 版本逐位一致。

数值验证时另有一个微基准曾短暂共享 worker CPU，因此不使用双模型 shadow 的耗时作性能结论；数值和业务字段检查仍有效。上表来自之后单独执行的、按原节奏的单模型回放。
