# Empty-side self-best orders, 2026-09-29

During limit-up/down one-sided books, self-best orders can have no
same-side reference price. mdserver IVOBook::InsertOrder records their
identity but does not add them to the matching book.

The old NativeBook rejected zero-price self-best orders when the same
side was empty. With a nonzero wire price it incorrectly added that
price, potentially creating a crossed book.

NativeBook now retains a zero-tick cancellation-only locator. Cancellation
removes the locator. It never contributes a price level, volume or age
aggregate. A fill against this identity is rejected before either book
side is mutated. Reset clears identities. Unknown cancellations remain
errors.
