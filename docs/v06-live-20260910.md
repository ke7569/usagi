  projection, shared two-layer GRU, four outputs ordered 15/30/60/120 seconds.
- B15 is the only pricing prediction. Strict finite same-sign MH4 gates expansion
  relative to static holdings; reduction subtracts all same-side reservations.
- Inference starts at 09:30, carries state across lunch, and does not skip the
  pre-09:32 training warmup. Expansion starts at 09:33. Offset is explicitly 1.0.
- Package offset/bias schedule, quote ratio 10, fixed skew 1 bps, bias factor 0.3,
  position scale 500000 and global directional skew (5% saturation, 10 bps max).
- Existing 20-stock static holdings and 200-share per-order cap retained. The
  research target capital is not used to increase real holdings.
- Real Quote limit orders and Hit orders cancelled after one second. Cancel
  request keeps reservations; only confirmed terminal reports release them.
- Real order cumulative fills and trade amounts are deduplicated independently.
  Missing trade amounts close admission until the corresponding reports arrive.
- Failed account/position queries retry without converting unknown holdings to
  zero. The dedicated TD does not forward failed position responses as success.
- Global base uses the actual day's first valid auction/continuous execution,
  with day validation. Snapshot previous-day OpenPrice is not substituted.
