# 2026-08-17

## Summary

Implemented the separate SSE opening Snapshot GRU model profile from the
external handoff. The existing 50-factor `v04-legacy-midmix-sse` runtime is
unchanged. The new profile has independent 36-factor baseline and 95-factor
Snapshot+Auction59 arms, native CPU inference, fail-closed time routing, and a
reproducible offline package.

## SSE Tick Model And Handover

- Verified the newly uploaded `v04-legacy-midmix-sse.tar.zst` completely with
  its `SHA256SUMS`. It is the 50-factor, no-scaler CompleteOrderBookSH L2 model
  already represented by `sse_model_runtime.*`; sampling is a strict
  next-local timestamp gap `>100us` at batch ends.
- Converted the uploaded `state_dict.npz` to `SSEMODL1` and replayed both CPU
  golden fixtures. Zero-input max errors were `4.17e-7` prediction and
  `3.87e-7` hidden; the continuous 4,102-row case was `1.07e-6` prediction and
  `1.13e-6` final hidden.
- Added `sse_hybrid_model.*` with asynchronous `on_snapshot` and `on_tick`
  entrypoints. Tick state advances before 09:35 as a shadow stream; Snapshot
  is selected for `[09:30,09:35)`, then tick is selected from exactly 09:35.
  Both states reset independently per instrument/day and there is no fallback.
- Added handover boundary, state-continuity and failure tests plus the combined
  model package builder.
- Final combined package:
  `src/t0-main/build/configs/sse-hybrid-model-20260817/sse-hybrid-model-20260817-final.tar.gz`
  (SHA-256 `27fe241b2b57fc6b6cc3d31a471509fb54ce2872b0b1885552ba102672228c87`).

## SSE Live Batch-End Sampling

- Added `sse-t0/market_data/sse_batch_end_sampler.*`, a deterministic
  two-phase trailing-edge detector for the strict local receive gap
  `>100000ns`. It coalesces the last CompleteOrderBookSH candidate per
  instrument, closes a late-timer batch before the next event mutates the
  book, suppresses duplicate cuts, and fails closed on feed health errors.
- Added a one-shot `CLOCK_MONOTONIC` timerfd adapter and the frozen
  turnover/100-second/mid-change sample gate. No periodic 10kHz publisher is
  used, and unchanged books never advance GRU state.
- Added prediction-only 2026-08-18 Shanghai market-data, hybrid strategy, and
  process configs. TD is empty and trading is disabled. The target host must
  inject its NIC, vendor decoder, daily SSE universe, positive turnover
  thresholds, and frozen factor adapter before startup.
- Added deterministic boundary/gate/timer tests and direct validation of the
  generated config. All focused SSE tests pass under the validated CentOS
  7.9/GCC 4.8.5 container; this environment has no `ctest` binary, so the registered
  test executables and offline Python test were invoked directly.
- Transfer package:
  `src/t0-main/build/configs/sse-hybrid-live-20260818/sse-hybrid-model-20260817.tar.gz`
  (SHA-256 `cc967c5058c763117b28090cd445736b5373f42180bb88693d75b8c8983e37ec`).
